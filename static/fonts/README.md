# Fonts (self-hosted)

Served by Streamlit from `static/` (`server.enableStaticServing = true`) and declared as
`[[theme.fontFaces]]` in `.streamlit/config.toml`. Variable WOFF2 files, latin and latin-ext
subsets (Indic fonts: their script subset only), from Google Fonts. Roles: `docs/DESIGN.md`.

| Family | Use | Licence |
|---|---|---|
| Newsreader (opsz, wght 400-600, roman and italic) | headings, wordmark, quotes | SIL Open Font License 1.1 |
| Schibsted Grotesk (wght 400-600) | UI and body text | SIL Open Font License 1.1 |
| IBM Plex Mono (400, 500) | numbers, page refs, IDs, costs, model names | SIL Open Font License 1.1 |
| Noto Sans Devanagari, Tamil, Kannada (wght 400-600) | Hindi, Tamil and Kannada text in the app | SIL Open Font License 1.1 |
